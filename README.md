# RL-INSTITUTE Student Management Portal

Responsive student-management front-end prototype with monthly fee tracking, daily attendance, marks, report cards and exports.

## Quick start
1. Extract this ZIP.
2. Open `index.html` in a modern browser.
3. Select **Open local admin preview** to explore using fictional records.
4. Use **Settings & Backup → Load / reset demo data** to add sample records.

## Privacy warning
The login page is a prototype only. It does **not** authenticate users. Local browser storage is not a secure database and is not shared between devices. Do not enter real student records until the backend is connected and access policies have been tested.

Read `SETUP_GUIDE.md` and `SUPABASE_STARTER.sql` before production setup.
